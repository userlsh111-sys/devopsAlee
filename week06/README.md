6주차 정리

1. Dockerfile: image(container 틀) 레시피, 글로 돼있음.
  -순서(명령어):
    -FROM: 이미지의 기반
      -가벼운 버전: -slim, -alpine
    -WORKDIR: cd
    -COPY (상대 경로)
    -RUN: 빌드(이미지 만들)시.
    -ENV (환경변수=값): 기본값을 이미지에 넣을 것("docker run -e"로 덮어쓰기 가능)
    -EXPOSE: 포트번호(실제론 안 열리지만 사용 예정이라 알려줌.)
    -CMD: 컨테이너 시작시(마지막 것만 효력 있음).
  -레이어: 한 레이어가 바뀌면 그 아래부터 전부 다시 빌드된다.
